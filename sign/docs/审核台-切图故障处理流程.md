# 审核台 · 切图故障处理流程(操作手册)

> 日期:2026-07-30 · 对应生产版本 `a1fd14a`
> 这份是**现在就能照着做**的操作手册,不是方案。凡是标 ⛔ 的表示**现在做不到**。

---

## 〇、先理清一件事:切图和字段是分开的

这一条不理清,下面所有判断都会跑偏。

```
一张照片 → qwen 一次调用同时产出三样东西:
   ① 切图框(这张照片上有几个单据、各在哪)
   ② 分类  (每个是护照/小票/百货/其它)
   ③ 字段  (票号、日期、姓名… ← **从整张照片上读的,不是从切片上读的**)
                                    ↓
            切片文件只是"给人看"和"给上家看"用的,字段不依赖它
```

**推论(很重要):**

| 现象 | 字段会不会错 |
|---|---|
| 框歪了 / 框大了 / 框重叠 | **不会**。字段从整图读,框只影响"你看到的那张图" |
| 少切了一张(4 张识别成 3 张) | **会**。那张票**压根没有记录**,不是字段错,是整条数据不存在 |
| 切碎了(一张切成两片) | **会**。碎片各自成任务,字段大多读不出来 |

所以处理优先级:**少切 > 切碎 > 框歪**。框歪最多是看着难受,不影响账。

## 一、六种故障形态 · 各自怎么操作

### 形态 ① 少切了(4 张小票识别成 3 张)← 你问的那个

**怎么发现**

- 客户组左侧队列里,这个客户组下面的小票条数和实际不符(要人数)
- 或者:点开任意一条小票 → 工具栏出现红橙按钮 **「同图 N 张单据 · 到原图看框」**
  → 点它 → 看到整张原图 + 框 → **哪块没被框住,那就是漏掉的**

**现在怎么处理(3 步)**

```
1. 在这张图的任意一条任务上,点右下角【更多 ▾】→【同图补小票】
   → 系统建一条空白小票任务,插在当前任务后面,指向同一张图
2. 跳到那条新任务,右栏字段全空 → 照着图**手工填**:免税店、小票号、团号、购买日期
3. 点【确认】
```

**⚠️ 现在的三个坑(必须知道)**

| 坑 | 后果 | 现在的绕法 |
|---|---|---|
| 补出来的任务**没有框** | 交付时会被护栏拦下,**图不进交付包** | 见下面「怎么给它补个框」 |
| 字段要**全部手填** | 慢,而且容易看错行 | ⛔ 暂时只能手填 |
| 如果原任务用的是**切片**文件 | 补出来的也是切片 → **不能画框** | 见形态 ⑥ |

**怎么给它补个框(让它能进交付包)**

```
1. 选中那条补出来的任务
2. 工具栏点【查看原图】
3. 点【画框】→ 光标变十字
4. 在图上把那张票**整个拖框进去** → 松手即保存
5. 图上方那条红橙提示「这张图进不了交付包」会消失
```

**⛔ 如果第 3 步没有【画框】按钮**:说明这条任务指向的是切片文件,不是原图。
按钮点不了,得走形态 ⑥。

---

### 形态 ② 切碎了(一张票被切成两片)

**怎么发现**:同一个客户组里出现两条小票任务,图看上去是同一张票的上半/下半,字段基本读不出来。

**怎么处理**

```
方案 A(推荐):【更多 ▾】→【按此店重切】
   → 用客户库原图,按这条任务当前的免税店档案重新调一次 qwen 重切
   → 旧任务删除,新切片归回同一批次
   ⚠️ 前提:客户库原图还在(工作区被重传/清理过就没有,会直接报错说明)

方案 B:留一条、删一条
   1. 在字段读得出来的那一条上补齐字段
   2. **确认这一条确实是要留的那条之后**,另一条【更多 ▾】→【删除这张图】
      (删除不可逆,见本文末尾那条 ⚠️)
```

---

### 形态 ③ 百货票被误切成碎片

**这一种有专门的一键处理**,不要用上面的方法。

```
在任意一条碎片任务上,右栏点【这其实是百货】→ 选【乐天百货 / 新世界百货 / 现代百货】
   → 系统会:①把整组原子定型为百货(免团号)
             ②**自动恢复被切碎的原图**(把碎片合回整图)
```

百货票面本来就是护照+小票同框、一图一票,不该被切。这个动作就是为它做的。

---

### 形态 ④ 分类错了(小票被认成护照 / 反之)

**不是切图问题,但常和切图问题一起出现。**

```
右栏【文件类型】区直接点:护照¹ / 小票² / 百货³ / 其它⁴(数字是快捷键)
或者用整句按钮:
   【改成护照】          —— 这其实是护照
   【改成其他(登机牌/包装等)】—— 这不是要的单据
```

---

### 形态 ⑤ 框歪了 / 框大了 / 两个框重叠

**先判断要不要管:**

| 情况 | 要不要管 |
|---|---|
| 框歪但两条任务票号**不同** | **不用管**。生产实测 94.5% 是这种 —— 两张真的票,字段各自填对了 |
| 框重叠且票号**相同** | **要管**。同一张票出了两条记录 —— 见形态 ⑦ |
| 框把票切掉一角,看不清字段 | 点【查看原图】看整图核字段,不用改框 |

**要改框的话:**

```
【查看原图】→【画框】→ 重新拖一个框(会覆盖旧的)
撤销:【清除框】(回到没有人工框的状态)
```

---

### 形态 ⑥ 补出来的任务用的是切片文件(画不了框)

**怎么发现**:点【画框】没有按钮,或者图上方提示写着
「这条记录和另一条共用同一个切片文件,没法分辨哪块是哪张票」。

**为什么**:框的坐标是按**整张原图**算的,画到切片上对不上位置 —— 不是没做,是坐标系不同。

**两条路(提示里也写了)**

```
路 A:【更多 ▾】→【按此店重切】—— 让系统重切一次,新切片带各自的框
路 B:**先建后删**(顺序别反)
      1. 回到指向**原图**的那条任务上 →【更多 ▾】→【同图补小票】重建一条
      2. 在新任务上按形态 ① 的方法画框、确认字段读出来了
      3. 确认没问题之后,再回去把旧的那条【更多 ▾】→【删除这张图】
```

> ⚠️ **删除不可逆**(2026-08-01 对着代码核过,`services/workbench_write/task.js` 的 `deleteTask`):
> - 是**硬删**:任务从批次里摘掉、图片文件一起删;
> - 还会写一条**墓碑**(`deletedSourcePaths`):以后补图/追加同客户时,这个来源路径会被跳过,
>   不会自己回来。代码注释的原话就是"删了就是删了"。真要找回只能重新导入或传一张新图(新路径)。
> - 已结算的组删不动(会返回 `delete_blocked_settled`)—— 那是台账证据。
>
> 所以凡是"删了再建"的写法,一律改成"建好验过再删"。中间那步失败的话,你至少还留着原来那条。

---

### 形态 ⑦ 同一张票出了两条记录(票号相同)

**怎么发现**:【查看原图】→ 该任务的框是**红色实线**,悬停显示
「和另一条任务票号相同,很可能是同一张票被框了两次」。

生产实测:130 对(占任务 0.506%)。

**怎么处理**

```
1. 两条都点开,核对哪一条字段更全/更对
2. 差的那条:【更多 ▾】→【删除这张图】
```

**⛔ 没有「一键合并」** —— 得自己判断删哪条。

## 二、图本身有问题(不是切图问题,但走同一个入口)

### 图模糊 / 缺 / 其它 → 要重拍

```
按【R】→ 再按【1】模糊 /【2】缺 /【3】其它     (两键完成,自动跳下一条)
或点底部【重拍 R】按钮
```

### 这张图漏传了别的单据 → 追加图片

```
【更多 ▾】→【追加图片】→ 选文件 → 自动上传并识别
(和「同图补小票」的区别:补小票是**同一张图**上再建一条记录;
  追加图片是**传一张新图**进来)
```

## 三、判断树:遇到问题先走这个

```
打开一条任务,发现不对 ——

图看不清/缺?
  └→ 是 → 【R】+【1/2/3】重拍,结束

这张图上的单据数量对不对?(点【同图 N 张单据 · 到原图看框】看整图)
  ├→ 少了一张 → 形态 ①(同图补小票 + 画框)
  ├→ 多了/碎了 → 是百货吗?
  │                ├→ 是 → 形态 ③(【这其实是百货】一键恢复原图)
  │                └→ 否 → 形态 ②(按此店重切 / 删一条)
  └→ 数量对 → 继续

分类对不对?
  └→ 不对 → 形态 ④(右栏改类型,或【改成护照】/【改成其他】)

图上方有红橙条「这张图进不了交付包」吗?
  ├→ 有,说"没有框" → 形态 ①下半(画框)
  ├→ 有,说"共用切片文件" → 形态 ⑥
  └→ 没有 → 继续

框是红色实线 + 悬停说"票号相同"吗?
  └→ 是 → 形态 ⑦(删掉多余那条)

以上都没问题 → 核字段 → 【确认 ↵】
```

## 四、按钮在哪(位置对照)

| 按钮 | 位置 |
|---|---|
| 适应 / 50% / 100% / 200% / 400% / ± / 滑块 / ↺ ↻ | 图片区**顶部工具栏** |
| 字段框 / 当前字段 | 同上(⛔ 存量图无数据,按钮是灰的,见第五节) |
| **同图 N 张单据 · 到原图看框**(红橙) | 同上,只在多单据同图时出现 |
| 查看原图 / 看裁切图 | 同上 |
| 框选 / 显示全部 / **画框** / 清除框 | 同上,**只在「查看原图」之后出现** |
| 「整张照片」缩略图 + 第 N/M 张 | 图片区**右下角**(可点标题条折叠) |
| **这张图进不了交付包**(红橙条) | 图片区**上方** |
| 文件类型 / 改成护照 / 改成其他 / 这其实是百货 / S活动票 | **右栏**上部 |
| 免税店 / 小票号 / 团号 / 购买日期… | **右栏**字段区 |
| 确认 ↵ / 重拍 R / 自动下一组 / **更多 ▾** | **右栏底部** |
| 追加图片 / 同图补小票 / 按此店重切 / 全部通过高置信 / 手动结算本组 / 恢复审核 / 台账订正 / 删除这张图 | **更多 ▾** 菜单里 |

## 五、现在确实做不到的(⛔ 缺口清单)

1. **补小票后字段要全手填** —— 应该用你画的框自动重读一次(能力已有,没接上)
2. **「同图补小票」和「画框」是两步** —— 补出来的任务默认没框、**必然被交付护栏拦**
3. **没有「一键合并同一张票」** —— 票号重复只提示,不给动作
4. **字段框(票号在哪一行)存量图看不到** —— 换 qwen 之后旧数据没有坐标;
   只有**新传的图**才有,而且百货不给
5. **切片视图上看不到框** —— 切片本身就是那个框;要在切片上标出"混进来的隔壁票",
   得先把裁剪矩形落库(待办 #37)
6. **画框只在「查看原图」之后可用**,而且整条流水线是键盘驱动的
   (`Enter` 确认 /`R` 重拍 /`1·2·3` 原因),框选相关**全要鼠标**

第 1、2 条合起来就是你说的"没有闭环" —— 方案在
[框选二次设计-两态闭环.md](plans/框选二次设计-两态闭环.md),等拍板。
