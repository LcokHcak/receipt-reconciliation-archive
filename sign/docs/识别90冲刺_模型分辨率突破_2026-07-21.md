## 一、类型识别(docType:护照/小票/百货/其他)对不对?

生产全量(9504 张已审)混淆:**总体 95.23%**。误分几乎全是一种:

| docTypeAuto → Final | 张数 | 说明 |
|---|---|---|
| 正确(对角线) | 9051 | — |
| **passport → receipt** | **407(占误分 90%)** | 百货票(常与护照同框)被 pass1 认成护照 |
| other→passport/receipt 等 | 46 | 零星 |

**当前代码(含两段式补救)在 246 张样本上复核**(护照/其他/百货):

| 类型 | 当前代码 | 生产旧 |
|---|---|---|
| 护照(99) | 100% | 99% |
| 其他(40) | 98% | 98% |
| **乐天百货(48)** | **100%** | 4% |
| **新世界百货(50)** | **100%** | 6% |
| 现代百货(6,极罕见) | 17% ⚠️ | 100% |

- ⭐**"百货被认成护照"这个 5% 误分的主因,当前代码的两段式补救已经根治**(乐天/新世界百货 4-6%→100%,补救 100% 触发)。这块只等部署。
- ⚠️**现代百货(HYUNDAI_DEPT)例外**:样本期整个生产只有 6 张(极罕见),其中 5 张被误判成免税店 SHINSEGAE、补救不触发。样本太小不下定论,但记为待查(现代百货 vs 现代免税店同名陷阱的延伸)。
- **换 qwen3-vl-plus 不伤百货分类**(专项复核 104 张):乐天百货 48/50=96%、新世界百货 49/50=98%(与 max 的 100% 同档)、现代百货 2/6(仍弱,小样本)。即模型切换对全链路(护照/百货/补救)安全。

## 三、票号冲 90%:四类方法效力(157 张对照 stage3)

| 配置 | 加权票号 | 新世界 |
|---|---|---|
| 当前(qwen-vl-max @1280) | 79.3% | 49% |
| +高清 2400 | 84.3% | 57% |
| +自洽投票 K4 | ≈同上 | 无效 |
| **⭐换 qwen3-vl-plus @2400** | **89.8%** | **71%** |

**各方法归因(实测)**:
1. **高清 1280→2400:+5pp(全店)**。存量切片本就 2400px,却被下采样到 1280 送 API——白丢的细节。乐天济州直接 78%→100%。
2. **自洽投票(裁票号区读 K=4 次多数表决)**:现代 87%→92%(随机误读有效),**新世界 60%→60% 无效**——新世界的错是"每次都读成同一个错号"的系统性误读,投票救不了。
3. **换 qwen3-vl-plus:+5.5pp(全店),新世界 57%→71%**。qwen3 认小字/年份位显著强(12 张新世界直读 max 3/12 vs qwen3 7/12)。系统性误读是模型能力问题,只有换模型能破。
4. **条码本地解码(零 API)**:采纳 13 对 1 错,近确定性,叠加在任何配置上。

**金标噪声校正**:qwen3 的新世界"错例"里有 2 张其实是金标录错(年份 28,qwen3 读对 26);全样本校正后 qwen3 加权 ~**91%**。

**逐店(qwen3+高清)**:乐天首尔 93% / 济州 100% / 新罗 93% / 爱宝客 95% / 现代 86% / 新世界 71%。
新世界仍是唯一低于 90 的店(16 位小字在切片上连 qwen3 也读不全)。

## 五、成本 / 延迟(⭐反直觉:更便宜)

官方单价(国内百炼,2026-07 核实):**qwen-vl-max 输入¥3/输出¥9 每百万token;qwen3-vl-plus 输入¥1/输出¥10**。
视觉 OCR 开销压倒性在输入(一图几千 token,输出 JSON 才百余),所以输入单价 3× 便宜决定成败。

用实验真实 token 数算每图成本:

| 配置 | 每图成本 |
|---|---|
| qwen-vl-max @1280(当前生产) | 1.54 分/图 |
| qwen-vl-max @2400 | 1.63 分/图 |
| **⭐qwen3-vl-plus @2400(赢家,含全量双读)** | **0.76 分/图** |

- **换 qwen3-vl-plus 约省一半成本**(0.76 vs 1.54 分/图),同时准确率 79→90。输入 ¥1/M 是 max ¥3/M 的三分之一,高清多出的 ~24% token 被远远抵消;输出略贵可忽略。按 ~1万图/天,日成本约从 ¥150 量级降到 ¥75 量级。
- **要注意的是吞吐/延迟而非钱**:qwen3 高清单图 ~5.5s(157张857s),比 max@1280 慢 2-3×;高清图并发上限会降,部署前按 project_perf_baseline 核 TPM,防预处理排队拖慢建档。
- 现代双读(always)再 +5pp(现代 86→~91),qwen3 下双读也便宜,基本不必省。

## 六、剩余瓶颈与真·天花板

- **新世界 71%** 是 qwen3 也啃不动的硬骨头:16 位小字在压缩切片(2400px 存量上限)上已到信息极限。**唯一实路 = P6:上传入库、压缩前的原相机图**(原图分辨率远高于 2400,qwen3 在原图上大概率 >85%)。这是把新世界从 71 抬到 85+、全局稳超 90 的正路,需改上传管道立项。
- 现代百货(极罕见)分类误判待查。
- 试过但无效已弃:自洽投票(对系统性误读无效)、便宜模型二遍(上一批已淘汰)、新世界公司登记号 793-85 防线(本轮 A/B 在噪声内,已回退)。
