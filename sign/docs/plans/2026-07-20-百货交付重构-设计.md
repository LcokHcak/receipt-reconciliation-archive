## 五件套设计

### 1) 乐天百货交付包(services/lotte_dept_delivery_export_service.js)

```
《{收票日期M.D}乐天百货小票》
  └ {门店店名:明洞|蚕室|釜山|仁川}          ← 改:店名夹(deptBranchName;未识别码原样),一店两码并一夹
      └ {购买日期M.D} {英文名}               ← 改:日期与姓名之间加空格(7.1 QIN SHIHUANG);姓名=selectGroupIdentity
          ├ {交易编号}.jpg                    ← 同框整图(票面自带打码护照,只露国籍)
          └ 护照.jpg                          ← 独立护照任务图(不打码);⭐无独立护照 → 同框整图兜底,不阻断
```

- missingPassport 从阻断名单**降级为 passportFallback 信息名单**(结果/预检可见,不拦导出)。
- 缺交易编号/缺门店仍阻断(文件没法命名,绝不出残包)。
- M6 撞名唯一化逻辑不动(判别护照号改用 selectGroupIdentity 同源)。

### 2) 乐天百货表格拆列 + 4) 上家列(services/monthly/library_mode_export_service.js)

COLUMNS:`免税分店` 一列 → `免税店`(明洞/蚕室/仁川/釜山)+`门店编号`(0394);`代理` 后加 `上家`。
- 存储不动(台账 branch 仍"明洞(0394)"单列),**只拆出口**:`名(码)` 正则拆;裸码行(07-13 前存量/未识别码)按行 shop 反查 deptBranchName,查不到店名留空、码照出。
- listRows SELECT 与展示列解耦(branch/shop 进 SELECT,免税店/门店编号为计算列)。

### 3) 新世界/现代百货交付链(mode_delivery 规则⑤,店家判定同规则②现代免税店先例)

```
{上家}                                  ← 大夹:任务 upstreamFinal||Auto||档案 defaults(新世界=梁总;现代=东方/金浦奥莱)
  └ {代理}                              ← customerAgentName(退 sourceGroupLabel 链,与台账 agent 同口径);空=未知代理
      └ {交易编号}                       ← ⭐一票一夹(2026-07-31 拍板 14-3):夹名=该票交易编号
          ├ {交易编号}.jpg               ← 夹里就这一张票(票面形态 4位-4位,与客户数据 Excel 同一个串)
          └ 护照.jpg                     ← 有独立护照就每个夹各放一份;没有则没有(缺护照在导出说明里点名)
```

- 承载在 planModeDelivery 内(新增分流:SHINSEGAE_DEPT/HYUNDAI_DEPT 小票不再进规则③模式夹):
  上家名自然成为渠道区(summarizeZones/entryInZone/单渠道切片/readiness 零改自动工作),不新增端点/前端。
- 同客户小票跨上家(现代:东方+金浦奥莱)→ 各上家夹各一份护照(跨区各一份先例)。
- 缺交易编码 → 阻断(带渠道区归因,与 S活动/现代池同口径);机票不进本链(百货无离境校验)。
- 乐天百货票仍走规则③(有独立包,用户没让动;文档立此存照)。

### 5) S活动双份修复(mode_delivery 规则④)

- 判定:`mode.includes('S活动') || task.sActivityFlag === true`(票级红标签为主源;模式名路径保留)。
- 副本落点不变:S活动/{模式}/{小票号}(flag 票的 {模式}=它自己的桶模式;未归类也成立)。
- 缺票号阻断口径不变。builtin_export_plan_specs 规则④文案同步。

## 存量回填(scripts/oneoff/backfill_dept_upstream_agent.js,dry-run 默认,执行等用户批)

- 取行:台账百货行(shop→档案 family=DEPT)且(upstream 空 或 agent 空)。
- upstream:批次任务 upstreamFinal||Auto → 档案 defaults.upstream(新世界=梁总/现代=东方;金浦奥莱只能来自任务值,兜底不猜)。
- agent:任务 customerAgentName→sourceGroupLabel 链 → customer_library/<ws>/<cid>/customer.json agentName(与 backfill_customer_agent_name 同源)。
- 单行单列 UPDATE(幂等,row_hash 不含 upstream/agent 不动哈希);批次 JSON 纯读,低峰可跑无需停机。
