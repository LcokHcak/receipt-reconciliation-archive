# 配置台效果图:改什么 → 影响什么(P1 版,含生效边界)

> 2026-07-14,对应生产 release-c75377c。配置台在 `/admin/config`(仅管理员)。
> ⭐最重要的一句:**P1 阶段配置只作用于「台账 Excel 导出」这一条通路**。
> 审核台怎么审、结算怎么结、交付包怎么打,现在都**不受**配置台影响(后续 P2/P3 分期接入)。
> 改坏了怎么办:版本历史一键回滚 / 「回落出厂规则」一键还原,都是立即生效。

## 一、总效果图

```
┌─ 配置台(/admin/config)──────────────┐
│ 某模式(如 乐天SG-本司)的配置:        │
│  ①台账8列勾选   ②小票号导出形态       │
│  ③团号字面量    ④动作签  ⑤备注        │
└──────────────┬───────────────────────┘
               │ 保存即生效(新版本入库,盖版本戳)
               ▼
      ┌────────────────────┐
      │  模式规则解析器      │←─ 没配置/坏配置 → 自动回落出厂矩阵(29条),系统永不因配置挂
      └────────┬───────────┘
               ▼
   ✅ 立即生效:【台账 Excel 导出】
      ├ ①勾掉的列 → 导出时该模式的行,这些列留空(数据仍在系统里,只是不写进台账)
      ├ ②票号形态 → 导出时把纯数字票号还原成 带杠19位/含字母14位 等原串形态
      └ ③团号字面量 → 该模式团号列固定写这个字(如机场票写「无」)
               │
   ⏳ 暂不生效(后续分期):
      ├ ④动作签/⑤备注 → 审核台的橙签显示目前仍走出厂矩阵(P3 接配置后跟随)
      ├ 审核台必填字段 → P3(店家档案为基线+模式微调)
      ├ 文件夹交付包结构 → P2(导出 DSL+预览)
      └ 结算逻辑 → 不进配置台(冻结区)
```

## 二、逐控件效果表

| 你改的东西 | 立即效果 | 不影响 |
|---|---|---|
| **台账列勾选**(收票日期/代理/购买日期/小票号/团号/姓名/护照号/出境日期) | 下一次导出台账起,该模式的行按新勾选出列;勾掉≠删数据,只是不写进 Excel | 审核台照旧全字段审(统一审核+出口过滤的架构不变) |
| **小票号导出形态** | 导出时按形态还原识别原串(审核员手里永远是纯数字,格式是导出层的事) | 审核台票号输入/校验 |
| **团号字面量** | 该模式导出的团号列恒写此字(留空=照票面) | 预匹配/团号表 |
| **动作签勾选** | 存进配置(P3 起审核台橙签跟随) | ⚠️当前审核台橙签仍显示出厂矩阵的动作 |
| **规则备注** | 存进配置(P3 起随橙签展示给审核员) | 当前审核台 |
| **保存(带修改备注)** | 立即生效=新版本;两人同时改,后保存的会被拦「已被他人修改」 | 已经导出过的历史文件不回溯 |
| **版本历史·回滚** | 点哪版哪版立即生效 | 历史版本永不删除 |
| **回落出厂规则** | 停用自定义,立刻回到内置 29 条矩阵口径 | 自定义历史仍在,随时可回滚回来 |
| **新增模式**(手输或点覆盖率横幅的芯片) | 该模式串从「未配置(默认全记)」变为有明确配置 | 团号表本身 |
| **黄色冲突提醒** | 只提醒不拦存(如"不记小票号列却配了形态") | — |

## 三、三个安全兜底(为什么敢放手改)

1. **出厂兜底**:没配置/配置损坏 → 该模式自动按内置矩阵走,和配置台出现之前一模一样;
2. **版本戳**:每次导出用的配置版本记录在日志(config_hit),"这批当时按哪版规则导的"永远答得上;
3. **一键回滚/回落**:改错了 30 秒内可以回到任何历史版本或出厂。

## 四、改完怎么验证

改完某模式 → 找一个含该模式的已结算批次 → 资料库导一次台账 → 对比该模式行的列。
(P2 会加"dry-run 预览":不用真导出,页面直接显示会产出什么。)
