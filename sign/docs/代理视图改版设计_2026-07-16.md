# 代理视图改版设计(2026-07-16,用户拍板 7 点已并入)

> 定位:**代理视图 = 以代理为轴的进度大面板**,双视角——已收客户组(管理进度)/未收客户组(推动补票)。
> 与审核台数据实时联动、每条可互相找回;按数据规则自动产任务;可视化为了"一眼看懂、顺手操作"。
> 用户原始需求=两张 mockup + 修改说明(2026-07-16);本文档是其工程化落地方案。

## 用户拍板(2026-07-16,7 点)

1. ✅ **账单节奏=每日给**:上家每日提供《卖出明细账单》,未收对账按日滚动。
2. ✅ **未归属兜底桶**:账单行团号查不到代理(团号缺/团号表未命中)→ 归"未归属"桶,不凭空消失。
3. ✅ **超 7 天起算点**=该行**第一次出现在未收清单的日子**(那次账单导入对账时),非购买日期。
4. ✅ **状态四档**:待收 / 部分已收(仍缺) / 已收(变灰) / 超7天未收(红);"图收了还在审"算**部分已收**。
   (mockup 另有「无需补(人工标记)」=操作员手动豁免态,保留为第五个人工态,行同样变灰。)
5. ✅ **未建档客户明示**:纯未收客户(系统里没这个人)不留死按钮,显示「未建档」徽标,深链只在建档后出现。
6. ✅ **退款/退货行排除**:transaction_type≠sale 的账单行不进未收清单(它们本来就不该有票)。
7. ✅ **权限**:操作员可读(未收数据按代理分、不属于任何操作员,全员同一份);任务勾选 reviewer 可操作。

## 三、B 未收客户组(新增页面)——核心

### 数据链(为什么这么设计:真相只有两处,未收=派生可重算)

```
每日导入《卖出明细账单》(现有账单管理导入,按行哈希幂等去重,重复导不炸)
        ↓ 导入完成自动触发 + 页面手动刷新按钮
自动对账:账单行(仅 sale,排除退款/退货) ⟂ 已收台账(审核通过结算落库的票)
        按 票号+店 投影匹配(与账单匹配 bill_match 同一套归一口径,不另造第二副本)
        ↓
没配上的账单行 = 未收票 → 按 护照号+团号 归并成"未收客户组"
        ↓
代理归属:账单行团号 → 团号表 → 代理;查无 → 「未归属」桶(拍板②)
        ↓
左栏按代理分列(与已收页同构),中间=该代理的未收清单
```

**设计原则**:未收清单是**派生视图**(账单+台账随时能重算,不怕算错),只有两样东西不可派生、单独落一张小状态表:
- `first_seen_at`:该未收行(键=工作区+票号+店投影)**第一次被对账发现的时间**——超7天红的起算锚(拍板③);
  后续每日重算,已存在的行不重置计时;
- 人工标记:「无需补」豁免(谁标的/何时/备注)。
真相不搬家、状态可重建,符合本仓库"派生可重算,锚点才落库"的架构口径。

### 未收行字段(拍板过的 8 列)
序号 / 姓名 / 护照号 / 团号 / 小票号 / 图片数 / 免税店 / 模式
- 全部来自账单行(店=store_family+分店,模式=账单 mode);
- **图片数=已补收图数/应收票数**(如 1/3):应收=该客户组未收票行数,已补收=系统里已找到的对应票图数。

### 状态四档(拍板④)+ 判定规则

| 状态 | 判定 | 展示 |
|---|---|---|
| 待收 | 无任何补收动作,first_seen_at ≤ 7 天 | 正常显示(黄标) |
| **部分已收(仍缺)** | 客户组部分票已进台账,**或图已收还在流程里**(建档/批次/审核中,未结算)——按护照号/票号在在途任务里能找到 | 黄标+进度(1/3) |
| 已收(补齐) | 该组全部未收票都已审核通过进台账、对账匹配 | **整行变灰**,任务自动完成 |
| 超7天未收 | first_seen_at + 7 天仍未齐 | **红标+置顶提示**(拍板③起算) |
| 无需补(人工) | 操作员手动标记豁免(mockup 保留态) | 变灰+标记人留痕 |

### 与审核台的联动/找回(拍板⑤)
- 未收客户**已建档**(护照号能在系统客户里找到)→ 行尾显示深链:跳客户档案/审核台定位(复用现有 buildReviewDeepLink);
- **未建档**(系统里没这个人)→ 显示「未建档」灰徽标,**不渲染跳转按钮**——界面明示,无死按钮;
- 补收闭环:确认未收 → 再次收图 → OCR → 审核 → 结算进台账 → **下一次对账自动把状态翻到部分已收/已收**(无需人工回填)。

### 任务提示(核心设计原则 3)
- 每个未收客户组自动生成一条 workflow_task(due_at = first_seen_at + 7 天):现有任务体系自带超期判定(overdue),到期自动红;
- 收齐→任务自动完成;人工标「无需补」→任务取消;
- 已收页的任务勾选与它同一套机制,操作员在一个任务列里看到两类任务。

### 《未收清单.xlsx》导出(B-b 部分)
- 入口:未收页右上「导出未收清单.xlsx」(资料库交付页可加同款入口,同一个端点);
- 结构:**sheet1=总表**(汇总所有代理所有模式)+ **sheet2..N=每代理一张**(sheet 名=代理名,内含该代理全部模式的未收行)——手法照资料库"每模式一 sheet"现成实现;
- 字段(用户模板):返点模式 / 免税分店 / 代理 / 购买日期 / 团号 / 姓名 / 护照号 / 小票号 / 品牌
  ——全部来自账单行+代理归属,账单表逐列都有;
- 「未归属」桶单独一张 sheet 放最后,不混进任何代理。
