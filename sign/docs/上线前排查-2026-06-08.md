## 🟥 P0 — 上线前必须处理

### 1. 手动录入页(ManualEntryView)用 mock 数据 + 写死汇率/返点 〔代码〕
- **现象**:`frontend/src/views/v2/ManualEntryView.vue` 无条件 `getManualEntries()`:
  - `entries = [...seed.recentEntries]` → 操作员看到的「近期录入」是**假历史**;
  - `netUsd = netKrw / seed.exchangeRate.krwToUsd` → USD 用**写死的 mock 汇率**算;
  - `commissionUsd = netUsd * seed.rebateRate` → 返点用**写死的 mock 比率**算。
- **后端**:`services/monthly/manual_entry_service.js` 已要求 `exchangeRate>0`(否则 422),
  但**全仓没有权威汇率源**——汇率是前端传的常量。
- **风险**:操作员据假数字录入、对外报的 USD/返点会错。
- **建议**:
  1. 在月度配置加「本月 KRW→USD 汇率」(放 workspace metadata 或与扣点表同级),后端从配置取,不信前端;
  2. 「近期录入」改读真实接口,无数据就显示空,**不要 mock**;
  3. 前端 `netUsd/commissionUsd` 改用配置汇率。

### 2. 弱口令 + Secure cookie + TLS 〔部署/运维〕
- 默认 `admin/admin123`;`SIGN_AUTH_COOKIE_SECURE` 当前 false(纯 HTTP 才能登录)。
- **建议上线 checklist**:改强密码 → 确认服务器 TLS → 设 `SIGN_AUTH_COOKIE_SECURE=true`
  + 已有安全响应头中间件(create_app.js)可考虑加 HSTS。**非代码改动,别在纯 HTTP 上盲开 Secure。**

### 3. npm 依赖 high 漏洞:`tmp` 路径穿越 〔代码/依赖〕
- `npm audit`:4 个(3 moderate + 1 **high**),high 是 `tmp` GHSA-ph9p-34f9-6g65(transitive)。
- **建议**:开干净分支跑 `npm audit fix` → 全测 + build 回归 → 通过再上。**不手加新运行时依赖**。
