Receipt Assistant 收款凭证助手
===============================

一、工具说明

Receipt Assistant 是本地运行的签字单批量处理工具。
系统不需要数据库，运行和文件处理均在当前电脑完成。

最终生成的 PDF 保存在 completed 文件夹。
工作台只显示当前批次的处理状态。


二、使用步骤

1. 放入原始 PDF
   将需要匹配的原始 PDF 放入 originals 文件夹。

2. 启动系统
   首次使用先双击 install_env.bat。
   安装完成后双击 start.bat。
   系统会自动打开 http://127.0.0.1:8888。

3. 上传签字图片
   在“上传中心”选择或拖入 JPG、JPEG、PNG 图片。

4. 工作任务处理
   在“工作任务”查看当前批次进度。

5. 文件名核验
   OCR 成功并已匹配 PDF 的任务会进入文件名核验。
   必须由用户点击“通过”后，系统才会生成结果。

6. 异常处理
   OCR 失败、PDF 未匹配、PDF 匹配冲突、生成失败和流程异常会进入异常处理。
   可重新识别、选择 PDF、忽略或重新处理。

7. 结果浏览
   已生成且待确认的结果会显示在结果浏览中。
   请确认结果正确后再标记完成。

8. 复制结果
   从 completed 文件夹复制最终 PDF。
   completed 文件夹是正式交付成果目录。

9. 完成当前批次
   当所有任务均处理完成后，可点击“清空工作台”开始下一批。
   清空工作台不会删除 completed 中的 PDF。


三、注意事项

- 本工具为本地工具，正常运行不依赖外网或数据库。
- 不要在处理过程中手动删除 uploads 中的图片。
- uploads 根目录保留上传原图；pending、approval 仅用于异常工作副本。
- completed 文件夹为最终成果，请定期备份。
- 每批完成后可清空工作台，避免历史任务影响下一批。
- 不要同时运行多个 Receipt Assistant 服务窗口。
- 不要直接修改 config.json；如需更改目录，请在系统设置中操作。
- 使用 Edge 或 Chrome 浏览器访问系统。


四、常见问题

1. 页面打不开
   - 确认 start.bat 窗口仍在运行。
   - 浏览器手动打开 http://127.0.0.1:8888。
   - 如果提示端口 8888 被占用，请关闭旧服务窗口后重新启动。

2. OCR 未就绪
   - 启动后 OCR 首次加载需要一定时间。
   - 等待顶部状态显示“OCR 就绪”后再上传。
   - 长时间未就绪时，查看启动窗口中的错误信息。

3. 上传失败
   - 仅支持 JPG、JPEG、PNG。
   - 确认图片没有损坏且不是空文件。
   - 上传失败接口会返回 JSON 错误信息，不应出现网页 HTML 错误。

4. 结果浏览不显示
   - 确认文件名核验已经点击“通过”。
   - 确认任务状态为生成成功且结果仍为待确认。
   - 已确认完成的结果不会继续显示在待结果浏览列表。

5. 异常数量不一致
   - 异常角标、顶部异常数量和异常列表采用同一规则。
   - 可刷新页面；仍不一致时关闭旧服务并重新启动。

6. 端口被占用
   - start.bat 会明确提示“Port 8888 is already in use”。
   - 关闭其他 Receipt Assistant 窗口。
   - 如果系统已经运行，可直接访问 http://127.0.0.1:8888。


五、文件夹说明

originals  原始 PDF
uploads    当前批次上传图片
completed  最终生成 PDF
logs       工作记录、任务状态和报告
debug      故障排查目录，正式包初始为空
wheels     Python 3.10 离线安装依赖


六、备份建议

建议定期备份：

- completed
- originals
- config.json
- logs
